What is Rove?

Rove is a social media app based around a map. Users can create events, join plans, meet new people, and discover fun activities nearby. It can be used to make new friends or simply organize plans with your existing friend group.

Main Features

🗺️

Interactive Map

Users can explore nearby events and plans directly on a map, making it easy to see what is happening around them.

📍

Create Events

Users can place an event on the map with a title, location, date, time, and description so others can join.

🎉

Join Plans

People can join public plans or events that interest them, helping them find things to do in their area.

👥

Make Friends

Rove helps users connect with new people who share similar interests and want to participate in the same activities.

💬

Social Interaction

Users can communicate, check who is going, and organize details before meeting up.

⭐

Plan Inspiration

Even if users do not want to join an event, they can use Rove to get ideas for what to do with friends.

How Rove Works

1

Open the Map

The user opens Rove and sees nearby events and plans on the map.

2

Choose or Create

The user can join an existing plan or create a new event for others to see.

3

Connect

Users can invite friends, meet new people, and organize the details.

4

Enjoy the Plan

Rove helps turn ideas into real social experiences.

Quality Assurance & Testing

To ensure a smooth, bug-free social experience on Rove, we integrated robust testing practices directly into our development lifecycle. This allows us to scale confidently while ensuring core app modules always remain functional.

🎭

Playwright E2E Tests

We write End-to-End tests simulating exact user actions—such as toggling complex dynamic forms, typing validation credentials, and verifying map views.

🚀

GitHub PR Pipeline

Every single pull request triggers automated tests. Code cannot be merged into production unless all test cases pass cleanly inside headless target environments.
